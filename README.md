# Flight-Booking-System-in-C

All students are required to utilize the following structured modules while developing their
project. These modules ensure efficient programming practices, organized data handling, and
secure operations. Adhering to these guidelines will improve project quality and functionality.
Mandatory Modules for Project Implementation:

1. User Authentication Module – Ensures secure access by validating user credentials and
storing them securely. Unauthorized access will be restricted.
2. String Manipulation Module – Provides custom functions for string operations such as
copying, concatenation, searching, and comparison for efficient text handling.
3. Record Handling Module – Utilizes structures and typedef to manage records
efficiently, ensuring smooth data storage and retrieval.
4. File Handling Module – Manages data storage using files, ensuring efficient reading,
writing, and organization of different types of information.
5. Main Driver Module – Acts as the central program controller, integrating all modules,
handling user interactions, and ensuring smooth execution.
6. Report and Presentation – A well-documented report and presentation must be
prepared, outlining the project’s design, implementation, and outcomes.

Students must strictly follow this modular approach for their project submission. Non-
compliance may result in deductions in evaluation. For any queries, contact the project
coordinator.
